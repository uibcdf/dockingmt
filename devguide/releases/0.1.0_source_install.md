## Environment and source inputs

The current profile is Linux x86_64, Python 3.11–3.14, Conda channels `uibcdf`
then `conda-forge` with strict priority. This is source-assisted installation.
MolSysMT needs its supported Rust toolchain and system C/C++ compiler. Use a
resource-managed build environment with one worker and sufficient memory for
that native construction; the hosted profile records its actual tools and uses
one logical CPU/low priority and a 5 GiB process address-space cap. The shared
workstation's interrupted local native build is not restarted by this recipe.

```bash
git clone https://github.com/uibcdf/dockingmt.git dockingmt-source
cd dockingmt-source
git checkout 0.1.0
CONDA_CHANNEL_PRIORITY=strict conda env create --name dockingmt-010 --file devtools/conda-envs/test_env.yaml
conda activate dockingmt-010
python -m pip install build==1.6.1 setuptools==84.0.0 wheel==0.48.0 versioningit==3.3.0 setuptools-rust
```

The bootstrap supplies third-party tools and initial support-package baselines.
The reviewed final profile intentionally replaces SMonitor, DepDigest and
PyUnitWizard with the exact development sources below, alongside ArgDigest,
MolSysMT and MolSysViewer. Their [source profile](../../devtools/source_0_1_0_current.toml)
is the machine-readable authority; public package minima do not change.

```python
import subprocess
import tomllib
from pathlib import Path

profile = tomllib.loads(Path('devtools/source_0_1_0_current.toml').read_text())
sources = Path('.molsyssuite/source-0.1.0-user').resolve()
sources.mkdir(parents=True, exist_ok=False)
for name, commit in profile['sources'].items():
    target = sources / name
    subprocess.run(
        ['git', 'clone', '--no-checkout', f'https://github.com/uibcdf/{name}.git', str(target)],
        check=True,
    )
    subprocess.run(['git', '-C', str(target), 'checkout', '--detach', commit], check=True)
```

Save that block as an owned setup script or execute it in Python from the source
directory. It creates fresh checkouts and refuses an existing destination.
Keep complete Git history/tags so the provider-owned version builders can
attribute their source versions correctly.

```bash
export CARGO_BUILD_JOBS=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 RAYON_NUM_THREADS=1
```

Apply the build host's CPU/allocation limits to these commands and their
descendants. The single-worker variables do not reserve memory or CPUs. Once
qualified and tagged, the final version check must show `0.1.0` from the installed
prefix. For editable group development, use the separate [development route](../DEVELOPMENT.md).
