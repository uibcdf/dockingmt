# Independent installed reconstruction of a stored workflow

## Accepted requirement and existing route

E5 under [the complete plan](../PRE_STABILIZATION_PLAN.md) requires a stored
representative workflow to be independently reconstructable to the degree
supported by its backend/environment. Reuse the existing 1IEP reference and
displaced-box replay, whose [historical #16 contract](../archive/replay_1iep_reference_and_control_from_saved_manifests.md)
is resolved. It retains authenticated SDF/PDBQT bytes, an explicit atom map,
recorded tolerances, one reference/three control poses and adverse-input checks.
That separate-process evidence does not itself qualify a new installed client
or discharge the whole current E5 audit. Preserve its producers and outcomes.

## Work and acceptance

1. Inspect the retained records, current replay implementation and declared
   unshipped installed-test support. Authenticate actual input/helper/data bytes;
   list reconstructed versus missing information. Molecular inspection JSON is
   comparison evidence, not a restoration codec. Reuse supported MolSysMT tools.
2. Select an exact current consumer artifact and actual dependency/native
   composition in a separate source-free receiving prefix/process. Original
   checkout paths, live objects and editable finders cannot supply runtime or
   scientific inputs. Original producer and new receiving identities stay distinct.
3. Execute both stored workflows through the existing supported reconstruction
   route from captured inputs, comparing native version, source/map, preparation
   assumptions, protocol, boxes, complete populations, atom order, scores,
   coordinates, source-referenced RMSDs and control classification. Freeze
   physical-unit tolerances before execution; preserve all original/new outcomes.
4. Receive corrupt/missing input and mismatched-map/protocol controls, with
   actionable diagnostics before native work where required. Preserve source/
   result nonmutation, caller units, detached outputs and a complete workflow
   missing-information audit. Source tests alone cannot receive native execution.
5. Register the exact finite calculation, native/metric calls, inputs and
   resource limits before launching. Run serially on one logical CPU at low
   priority, one native/build worker and monitored RAM reserve. Preserve failures
   and interruptions; no automatic restart after headroom interruption or manual
   CI under the incremental `[skip ci]` route.
6. Seal complete receiving artifacts and independently verify saved evidence.
   Audit every criterion before closure. Externally prepared chemistry remains
   unassessed; software replay does not establish independent-panel accuracy,
   universal deterministic replay, affinity or unrestricted molecular restoration.

## Disposition and next action

entry points, installed-support declarations and original tolerances, then
register the candidate/population/controls. Do not start native work from this
proposal alone or invent a replay engine. An existing qualified composition
can be received independently of [#80's held newer-provider build](../validation/e4_evidence_catalog_fix_2026-11-07.md);
do not mix artifacts or advertise public compatibility. Missing reusable molecular

retains full Core C0–C6/Extended E1–E5, scientific and stabilization scope.
