# Document Map

Start with the current-work documents. Design documents explain intent; dated
audits, notebooks and receipts retain evidence at their stated source/artifact
identities. A historical "next" action is not automatically today's queue.
Use the relevant workflow evidence rather than reading every experiment before
making a bounded contribution.
